# Video pipeline: картинки + голос, бесплатно и без вашего компьютера

Работает на серверах GitHub Actions. Компьютер можно выключить.

## Как пользоваться (можно с телефона)

1. Заполните файлы в `video-pipeline/project/`:
   - `scenes.txt` — по одной сцене на строку (130 строк = 130 картинок);
   - `style.txt` — общий стиль для всех картинок;
   - `voice.txt` — текст озвучки.
2. GitHub → вкладка **Actions** → **Video pipeline** → **Run workflow**.
3. Через ~1 час откройте запуск и скачайте архив **result**:
   - `images/001.jpg … 130.jpg`
   - `voice.mp3` и `voice.srt` (субтитры для CapCut).

Если какие-то картинки не сгенерировались, запустите ещё раз.

## Что используется

- Картинки: Pollinations.ai (модель FLUX), бесплатно, без ключа. Это не Nano Banana.
- Голос: Microsoft Edge TTS, бесплатно, без ключа.

Бесплатные сервисы могут поменять лимиты без предупреждения.
